# Stardust: Ideas

A scratch space for thoughts before building anything. Nothing here is decided.

Space game about harvesting asteroids, moons, planets, and stars, all while making yourself into a technological celestial body.

---

## Ships

Ships are made of modular parts.

| Part | Function | Cost / notes |
|---|---|---|
| Hull / Frame | Structural base that other parts attach to | |
| Storage bay | Raises maximum matter capacity | |
| Grinder | Harvests matter it touches | Intake uses a funnel (see Notes) |
| Drill | Breaks matter it touches | Costs a tiny amount of electricity |
| Mass cannon | Fires mass at targets | Costs matter, likely iron |
| Laser cannon | Fires a laser | Costs a lot of electricity |
| Tractor beam | Moves matter without touching it | |
| Thruster | Gives speed | |
| Fusion converter | Makes material out of elements | |
| Fission converter | Breaks elements into smaller elements | |
| Heat sink | Holds more heat before reaching dangerous levels | |
| Radiator | Dissipates heat into space | |
| Heat ejector | Launches hot matter out, heavily lowering heat | Costs matter |

---

## Notes

- **Matter:** any element or material that gets harvested, such as iron, silicon, helium, or hydrogen.
- **Grinders:** always have odd funnels that make resource gathering more challenging.
- **Part size:** parts take up multiple slots and are always cuboid.
- **Heat:** tracked per part. Heat spreads between neighboring parts over time.
- **Slots:** unlimited. Ships will eventually grow bigger than stars.

---

## Building

- **Copy and paste:** a feature.
- **Build time:** parts take 10 seconds by default. Some parts take longer.
- **Placing parts:** select a block from the build menu, then click a face of an existing block. The new block builds off that surface.
